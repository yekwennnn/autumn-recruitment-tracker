# 日报格式

Markdown 日报由 `new_only.json`（`scripts/dedupe.py` 的输出）渲染。渲染工作由 `scripts/digest.py render` 完成，SKILL.md 不需要手写格式化逻辑。标题里的季节标签、岗位方向标签都是 `digest.py` 从 `config.json` 的 `target_season_label`/`job_category_label` 读出来拼的，不是写死的字符串——下面模板里的"2026秋招"、"财务"、分数等都只是示例值。

按需传参，渲染的内容也随之增减：

| 参数 | 打开什么 |
|---|---|
| `--resumes` | 各岗位的匹配区块与深评统计 |
| `--evaluated` | "本次补评完成"小节 |
| `--applications` | "📮 投递待跟进"小节、已投岗位从截止预警里排除、页脚投递数 |
| `--plan` | 页脚的"本次发现：X 路"与自动降频说明 |

都不传时输出与 v1 完全一致（老用户/无简历场景兼容）。

## 区块顺序

1. 标题
2. 未导入简历提示行（如有）
3. **⏰ 网申截止预警**（如有）——最紧急的放最前
4. 新增岗位（按公司分组）
5. 本次补评完成（如有）
6. **📮 投递待跟进**（如有）
7. 页脚统计

## Markdown 日报模板（有新增时）

```
# 2026秋招 财务方向岗位监控日报 · 2026-08-01

## ⏰ 网申截止预警（7 天内）
- **还剩 2 天** — 某某银行 · 风控管培生（2026-08-03） · 84/100，建议优先投
  链接：https://...
- **今天最后一天** — 某集团 · 财务管培（2026-08-01）
  链接：https://...

发现 2 家新开放企业，共 3 个新增岗位（已深评 2，待深评 1）

## 某某银行
- **风控管培生** — 上海
  匹配：84/100 · 推荐投递 · 建议一键定制简历
  优势：Python+SQL 与JD硬性要求完全对口
  差距：JD偏好有金融实习经历，简历暂无
  截止：2026-08-03（**还剩 2 天**）
  亮点：CPA优先，2027届
  链接：https://...
  来源：牛客网 · 发现于 2026-08-01
- **总行科技岗** — 北京
  匹配：待深评（下次运行自动补评）
  亮点：...
  链接：...
  来源：...

## 本次补评完成（此前"待深评"岗位）
- 某咨询公司 · 数据分析岗 — 76/100，优势：...

## 📮 投递待跟进
- **待办到期** — 某科技 · 财务分析：一面，安排在 2026-08-01
- 已投 16 天无进展 — 某某集团 · 财务管培（可以催一下 / 找内推问进度）

当前已监控 12 家公司 / 27 个历史岗位 · 已深评 8 · 待深评 3 · 已投递 5（在跟进 3）。
本次发现：精简扫描 · 2 路（公众号-新启动公告扫描、公众号-公司池轮询）。
```

要点：

- 公司分组按"组内最高分"降序排（84 分的公司排最前），无分岗位殿后；组内也按分数降序。
- `建议一键定制简历` 尾缀只在 `score >= resume.min_score_for_action`（默认 70）时出现。
- 抓不到 JD 的岗位标 `匹配：JD未抓到，未评分`。
- 分档含义（常量在 digest.py 顶部，与 references/matching.md 严格一致）：≥85 高度匹配 / 70-84 推荐投递 / 50-69 备选 / <50 观望。

## 截止日期的渲染规则

- 岗位有 `deadline` 才渲染截止行；没抓到就整行不出现（**不要写"截止日期未知"占位**，那是噪音）。
- 剩余天数 ≤ `deadline.warn_days`（默认 7）时加粗提醒；当天到期写"**今天最后一天**"。
- **截止预警小节**只收：未过期、剩余天数在预警窗口内、**且尚未投递**的岗位，按紧急程度升序。已投的不再催——投都投了。
- 新发现但已经过了截止的岗位**不进新增列表**，只在页脚记一句"另有 N 个新发现的岗位已过网申截止，未列出"。

## Markdown 日报模板（无新增时）

```
# 2026秋招 财务方向岗位监控日报 · 2026-08-01

今日未发现新的财务方向正式校招岗位。

## 📮 投递待跟进
- 已投 16 天无进展 — 某某集团 · 财务管培（可以催一下 / 找内推问进度）

当前已监控 12 家公司 / 27 个历史岗位 · 已深评 8 · 待深评 3 · 已投递 5（在跟进 3）。
本次发现：精简扫描 · 2 路（公众号-新启动公告扫描、公众号-公司池轮询）。
```

这个"无新增"分支必须始终输出，不能空手退出；截止预警、补评、待跟进小节有内容时照常附上。**精简日没有新增岗位是正常的**，页脚的"本次发现：精简扫描 · 2 路"就是在解释今天扫描面本来就窄——不要因此额外加路数重跑。

## 未导入简历提示行

config `resume.enabled` 为 true 但档案不存在（或无 active_base）时，标题下一行插入（原文由 digest.py 生成）：

```
> 提示：尚未导入简历，本报告未做匹配评分。下次对话时把简历文件发给我即可开启匹配功能。
```

此时不渲染各岗位的匹配行（避免满屏"待深评"与提示行自相矛盾）。

## 自动降频说明行

有车道因连续零产出被自动降频时，页脚追加：

```
已自动降频的来源：aggregator-nowcoder——连续多次零产出，全量日仍会跑；想立刻恢复说一声即可。
```

这一行必须保留，它是"成本被压低了，但你知情且可逆"的凭据。
