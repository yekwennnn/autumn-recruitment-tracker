# 社招岗位发现

## 车道

```text
social-official-watchlist   每天，意向公司官网轮询
social-official-newcompany  每周，发现新公司官网岗位
social-wechat-watchlist     每天，官方招聘公众号补充
social-aggregator-liepin    每周，低频聚合补漏
social-aggregator-boss      每周，仅在官方来源不足时使用登录态
social-aggregator-other     每周，其他可信聚合平台补漏
```

BOSS、猎聘等平台是发现入口，不是最终事实来源。尽量回到公司官网，找不到官方页时标 C，不能把 C 当 A。

社招重点核实：岗位职级、最低年限、业务域、地点、远程/现场要求、到岗时间和截止日期。

输出契约与校招相同；每条必须保留完整 URL 和来源等级。
