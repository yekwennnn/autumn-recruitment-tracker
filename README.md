# 秋招求职助手（autumn-recruitment-tracker）

一句话说明：这是一个能让你的 AI 助手每天自动帮你"扫一遍"校园招聘信息、给每个新岗位打匹配分、看中了还能照着 JD 帮你改简历的小工具。你不需要会编程，也不需要懂什么技术名词，全程只要用聊天的方式跟你的 AI 说话就行。

## 这个东西能帮你做什么

正常情况下，如果你想盯着某个方向的校招岗位（比如财务、技术、市场、人力资源……随便什么方向），你得自己每天去牛客网、猎聘、51job 这些网站上一个个翻，还要盯着各家公司的招聘公众号，看看有没有新公司开岗位，再自己判断这是不是实习、届别对不对、之前是不是已经看过了、这岗位适不适合自己。

这个工具就是替你干这些苦活：

- **先读你的简历，给你一份简历分析**：你的三条优势（每条指出简历里哪句话支撑它）、两三条短板（会在哪一步卡住你），然后**推荐 2-3 个适合你投的岗位方向**并说明理由。之后所有找岗位、打分、改简历都按这份分析来。
- 每天自动去**公司招聘公众号**上找新开的校招岗位（公众号是校招信息最快的一手来源，这个工具专门盯它），每周再把牛客、51job、智联、猎聘这些平台全面扫一遍（默认只看正式校招，要不要顺便看实习由你自己选）。
- 自动把"你已经看过的岗位"和"今天新出现的岗位"分开，不会每天给你看一堆重复的。
- 每天清单里的每个新岗位都带一个 **0-100 的匹配分**，外加一句你的优势、一句你的差距，一眼看出哪个值得投。
- **盯网申截止日期**：快到期还没投的岗位会置顶提醒你"还剩 3 天"，过期的自动收起来不占版面。
- 看中哪个岗位说一声（或点一下），它就照着这个岗位的招聘要求帮你**改简历**——只用你真实的经历（STAR 写法，绝不编数字），每一版都存档，越用越懂你。
- **记你投了什么**：投了哪家、用的哪一版简历、进展到哪一轮。投出去两周没动静的会提醒你催一下，还能告诉你哪一版简历的过筛率更高。
- 全程自动运行，不需要你每天记得去打开。

它不预设监控任何行业——装好之后第一次使用时，你先把简历发给 AI（**它拿到简历之前不会问你任何问题**），它读完给你分析和方向推荐，再带着"从简历里看出来的答案"跟你确认几个问题（哪个方向、哪一届、要不要看实习），确认完才开始干活。不管什么方向，都是同一套流程。

## 你需要准备什么

- 一个能听你说话、能帮你操作电脑的 AI 助手，比如 Claude Code。（如果你现在正在用的就是这种 AI 聊天工具，那就够了。）
- 一份你的简历文件（PDF、手机拍照、Word、纯文本都行）。
- **不需要**：不需要会写代码，不需要看懂任何文件，不需要懂什么是 JSON、什么是命令行。这些全部交给 AI 来做。

## 不是 Claude Code 也能用

这个工具在设计上不绑定某一家 AI 助手。换别的 AI 助手也能跑：功能强的（会开子任务、会弹选项）体验最好；功能弱一点的会自动走简化流程——少开几路搜索、改用文字问答、简历先出网页版。改简历的规矩（只写真话、每句话面试都能答上）在哪个助手里都一样。

## 怎么开始用（全程跟 AI 聊天完成）

### 第一步：把工具下载下来

打开这个工具所在的网页（GitHub 仓库页面），找绿色的 **Code** 按钮，点开后选 **Download ZIP**，下载解压得到一个文件夹。（不会解压就把文件直接交给 AI，说"帮我解压一下"。）

### 第二步：把文件夹交给你的 AI，让它帮你装好

打开你的 AI 助手，把解压出来的文件夹路径告诉它：

> "这是一个自动监控校招岗位、还能帮我改简历的工具，帮我安装到我的技能目录里，装好之后告诉我。"

### 第三步：把简历发给它，看分析，再回答几个确认问题

装好之后第一次运行，AI 会先请你把简历文件发给它（PDF/拍照/Word/文本都行；Word 读不了它会教你转成 PDF）。**这一步它只会要简历，不会同时问你别的**——因为下面那些问题的答案基本都能从简历里读出来，先问等于让你白想一遍。

它读完简历会先给你一份**简历分析**：

- 画像速览（学历、专业、核心技能、经历主线）
- **优势 3 条**，每条都指明是简历里哪句话支撑的
- **短板 2-3 条**，说清楚会在哪一步卡住你（比如"没有相关实习，简历筛这关会减分"）
- **推荐 2-3 个岗位方向**，每个带契合度、推荐理由、这个方向常见的岗位叫法、想投的话得先补什么

看完分析，它才带着答案来确认几个问题——你是哪一届、想投什么方向（选项就是刚才推荐的方向）、要不要看实习、现在是秋招还是春招——你确认或者纠正就行。

回答完，AI 会把设置记下来，还会按你的方向生成一份 30-50 家公司的"重点监控名单"（之后想加谁减谁随时说）。

> 分析只根据简历里实际写着的内容，写不出来的它会直说"简历里没写，你补充一下"，不会替你猜。

### 第四步：先让它试跑一次

> "先手动跑一次这个监控，让我看看效果对不对。"

你会看到一份"今日新增岗位"清单，每个岗位带匹配分和优劣势。不满意就直接说哪里要调。

### 第五步：让它每天自动帮你查

> "帮我把这个设置成每天早上自动运行一次，不用我提醒。"

## 装好之后，每天会发生什么

每天到了设定的时间，AI 会自动：

1. 去公司招聘公众号上找新岗位——**两路：扫最近三天的"秋招启动"新公告，再轮询一批你的重点监控名单**（名单分批轮，几天转完一圈）；
2. 按你的方向和届别筛选，排除不相关的（选了"不看实习"的话实习也排除）；
3. 和已看过的岗位对比，只留真正新增的；
4. 对每个新岗位抓完整的招聘要求（JD），对照你的简历打 0-100 匹配分，顺便记下网申截止日期（每次最多深评 15 个，多出来的第二天自动补上）；
5. 生成清单：快截止的置顶预警、哪家公司、什么岗位、多少分、你的优势差距、投递链接、还有你投出去还没动静的那些；
6. 没有新岗位也会告诉你"今天没有新增"，不会什么都不说。

**每周挑一天（默认周日）会跑一次"全面扫描"**：除了公众号，还会把牛客、51job、智联、猎聘（选了看实习的话再加实习僧）和各种"秋招名单帖"全扫一遍，补上平时可能漏掉的。

为什么这么安排：公众号是公司自己发的一手消息，"今天谁开秋招了"只有它最快，所以天天盯；那些招聘平台上的信息大多是转载的，一天之内基本不变，天天全扫纯属重复花钱。这样每天的花费大概能降到原来的四分之一，而最要紧的一手渠道一天都没少跑。想改回每天全扫，跟 AI 说一声就行。

看到分数高的岗位，直接说"帮我照着第X个岗位改简历"（或点它给的选项），它就会走改简历流程。

## 改简历是怎么保证不瞎编的

这是这个工具最较真的地方：

- **先问清楚再动笔**：你提到的每段新经历（尤其"我用AI做过XX"这类），它会先问你具体做了什么、你和工具各干了什么、做到了什么程度，问清楚才写。
- **STAR 写法**：每条经历按"背景-任务-动作-结果"组织，结果只写真的——没有数字就写规模和状态（比如"个人使用，未对外发布"），**绝不编造指标**。
- **不硬凑**：岗位要求你没有的能力，宁可空着说明，也不往简历里塞。
- **保密**：涉及前雇主/客户数据的经历只写方法不写细节。
- 每次改完它会逐条告诉你改了什么、依据是什么，保证简历上每句话你面试都能答上。
- 改出来的每一版都存在档案里（哪家公司、什么岗位、改前改后分数），投得越多，它对你的了解越准。

## 投出去之后

改完简历它会问一句"投了吗"，你说投了，它就记一笔。之后随时可以跟它说：

> "字节让我去笔试了" / "那家银行挂了" / "我投了哪些还没消息的"

它会帮你记进展（已投递 → 简历通过 → 笔试 → 一面 → …… → offer），并且：

- 投出去超过两周还停在"已投递"的，日报里会提醒你催一下或者找内推问进度；超过一个月的会直接说"疑似已挂，可以考虑放弃了"。
- 约好的笔试面试时间到了会提醒你。
- 已经投过的岗位不会再出现在截止预警里——投都投了，催也没用。
- 问它"哪一版简历过筛率高"，它会按简历版本算给你看。**注意样本量**：校招投几十份，版本之间差几个百分点没有意义，它自己也会提醒你这一点。这个数字能告诉你的是"这一版明显不行"（投了十几个一个没过），不是"A 版比 B 版强 3%"。

## 你的简历安全吗

- 简历只存在**你自己电脑上**这个工具文件夹里的 `resumes/` 目录，不会上传到任何网站。
- 仓库自带保护配置（.gitignore）：就算你把这个工具文件夹分享给别人、或者传回 GitHub，你的简历、个人设置、历史记录也**不会被带出去**。
- AI 派出去搜岗位的任务里只带"画像摘要"（比如"2027届会计硕士，会Python/SQL"），不含你的姓名、电话、邮箱。

## 想直接出 PDF 简历？（可选）

不装任何东西也能用——AI 会给你排版好的网页版简历文件（浏览器打开就能看、能打印）。想让它一步到位直接出 PDF，就跟它说：

> "帮我装上做 PDF 需要的工具。"

（背后是 `pip install weasyprint pypdf`，macOS 上可能还需要 `brew install pango`；`pdfplumber`、`pymupdf` 是进一步的可选增强。装失败也不影响其他所有功能。）

## 定时运行时它会做什么、不做什么

- **会**：自动发现新岗位、自动抓 JD 打分、自动补评之前没评完的、提醒你哪些快截止了、提醒你哪些投了没动静。
- **不会**：改简历，也不会替你标记投递状态。改简历永远只在你在场、点头之后才做——因为动笔前要跟你核实经历的真实细节，没有你在场它不会替你编。

## 常见问题

**我要自己写代码或改设置吗？**
不需要。任何调整——换方向、改届别、加减监控公司、改每天运行时间——都直接跟 AI 用大白话说。

**这个会不会很贵，或者跑很久？**
工具内置了几道成本闸门：平时每天只跑两路公众号、每周才全面扫一次；出去找岗位的那些子任务用的是便宜的小模型（打分仍然由主模型亲自做，保证所有岗位一把尺子）；每次最多深评 15 个新岗位（可调）、同一个岗位永远只深评一次、每次最多核实 5 家新公司。具体花费取决于你用的 AI 助手的计费方式。

**这么省会不会漏岗位？**
工具会记账：每条渠道跑了多少次、找到过多少新岗位、其中多少个高分。想看就问它"各个来源的产出怎么样"。某条渠道连着好多次一无所获，平时就不跑它了（每周的全面扫描日照跑，所以不会永久失明），日报里会写明是哪条、怎么恢复。砍成本这件事有据可查，不是拍脑袋。

**我怎么知道今天为什么没找到岗位？**
日报最后一行会写"本次发现：精简扫描 · 2 路"还是"全量扫描 · 5 路"。精简日本来扫描面就窄，没有新增很正常，不用重跑。

**匹配分靠谱吗？**
它按固定的量表打分（硬技能 35 分、经验相关 25 分、学历届别 15 分、证书语言 10 分、意向契合 15 分），只认你简历里写了的和你亲口确认过的，不会"猜你应该会"。当参考很好用，但重要岗位还是自己点开 JD 确认一下。

**装好之后它没要简历、直接问我方向了怎么办？**
跟它说"先看我的简历再问"。正常第一次使用一定是先要简历、给你分析和方向推荐，然后才确认那几个问题——顺序反了就打断它。

**用了一段时间想换方向/换简历怎么办？**
换方向：说"帮我把监控方向改成XX"。换简历：把新简历发给它，说"用这份做我的主简历"，它会重新建档、更新画像。

**这个工具靠谱吗，会不会漏掉岗位或者搞错？**
它靠 AI 去各网站找信息再判断，不是 100% 精确。建议当作"帮你先筛一遍、缩小范围"的助手，重要岗位自己点链接确认。

## 给愿意自己动手的人

技术细节看 `SKILL.md`（运行步骤与降级策略）、`references/`（数据源轮转/评分量表/改简历流程/投递追踪）、`config.example.json`（全部可调项）。首次运行后实际设置在 `config.json`（不入库）。内嵌的排版工具箱与改简历指引在 `vendor/`，说明见 `vendor/README.md`。

几个常用的调节旋钮（都在 `config.json`，也都可以直接跟 AI 用大白话说）：

| 想干什么 | 改哪里 |
|---|---|
| 恢复成每天全面扫描 | `discovery.mode` 改成 `"full_daily"` |
| 换个日子做全面扫描 | `discovery.full_sweep_weekday`（0=周一，6=周日） |
| 彻底关掉某条渠道 | 把它的 lane id 写进 `discovery.disabled_lanes` |
| 调子任务用的模型 | `discovery.agent_model`、`resume.jd_fetch_agent_model` |
| 改截止预警提前几天 | `deadline.warn_days` |
| 改"投了多久算没动静" | `applications.followup_days` / `stale_days` |
