# 秋招求职助手（autumn-recruitment-tracker）

**一句话：** 从"今天有什么岗位"到"明天面试怎么答"，校招这一路上重复、琐碎、容易漏的活，它替你干。

**你要做的只有一件事：打字，跟 AI 说人话。** 不用写代码，不用看懂任何文件，不用记任何命令。

---

## 开始之前，三句实话

1. **你不需要会编程。** 这份说明里出现的每一句"跟 AI 说"，都是让你像发微信一样打字。
2. **你需要先装一个 AI 助手。** 这是唯一需要动手安装的东西，大约十几分钟，下面第 0 步手把手教。
3. **AI 助手是要花钱的。** 这个工具本身免费开源，但它得跑在 AI 助手上，而 AI 助手按套餐或用量收费。这个工具内部做了不少省钱设计（后面"要花多少钱"一节会讲），但不是零成本。心里有个数再开始。

---

## 它管哪一段

校招从头到尾是这么一条链，这个工具七个环节都在：

```
找岗位 → 算匹配 → 挖经历 → 改简历 → 填网申 → 记投递 → 练面试
```

以前你得自己每天翻牛客、猎聘、51job，挨个刷公司招聘公众号，判断这是实习还是正式、届别对不对、看过没有、适不适合；改简历时对着 JD 干瞪眼；同样的信息在几十家公司的网申系统里重填几十遍；拿到面试才发现不知道该准备什么。

现在这些是这样的：

| 它做的事 | 具体是什么 |
|---|---|
| **读懂你的简历** | 给你一份分析：3 条优势（每条指出简历里哪句话支撑）、2-3 条短板（会在哪一步卡住你）、**推荐 2-3 个适合你的岗位方向**并说明理由 |
| **每天找新岗位** | 主盯公司招聘公众号（校招消息最快的一手来源），每周再把各大招聘平台全面扫一遍 |
| **不给你看重复的** | 自动区分"你已经看过的"和"今天新出现的" |
| **给每个岗位打分** | 0-100 分，外加一句你的优势、一句你的差距，一眼看出哪个值得投 |
| **盯网申截止** | 快到期还没投的置顶提醒"还剩 3 天"，过期的自动收起来 |
| **陪你深挖经历** | 简历上轻描淡写的一行，背后压着一整段没说出来的事。七个问题帮你展开成可用素材——**同一段经历挖一次，改简历、写网申开放题、面试讲故事三处都能用** |
| **照着 JD 改简历** | 只用你真实的经历，绝不编数字，每一版都存档 |
| **帮你填网申** | 个人信息录一次存成档案，之后在企业官网表单里自动填。**填完停在提交按钮前给你核对，你点头才提交。** 身份证、密码、验证码这类一律不碰 |
| **记你投了什么** | 投了哪家、用的哪一版简历、进展到哪一轮；两周没动静会提醒你催 |
| **陪你排练面试** | 帮你出题、演面试官陪你练、面完把真题记下来。出题**基于你投这家时用的那版简历**——面试官手里就是那份，不是你最新那份 |

它不预设任何行业。财务、技术、市场、人力、供应链、产品……都是同一套流程，方向由你的简历和你的确认决定。

## 第 0 步：装一个 AI 助手

**这个工具不是一个能双击打开的软件**，它是一份"给 AI 看的说明书 + 一堆 AI 会用到的小工具"。所以你得先有一个能读文件、能上网、能操作你电脑的 AI 助手。

推荐用 **Claude Code 桌面版**（Mac、Windows、Linux 都有）：

1. 打开 **[claude.com/product/claude-code](https://claude.com/product/claude-code)**。
2. 点页面上那个大按钮——**Download for macOS**（在 Windows 电脑上打开时会自动变成 Windows 版）。
3. 下载完成后双击安装，跟平时装软件一样。
4. 打开它，用 Claude 账号登录（没有账号就现注册一个），按提示选好套餐 / 计费方式。

装完你会看到一个能打字聊天的窗口。**从这里开始，本文里所有"跟 AI 说"，就是在这个窗口里打字。**

> 这是整个流程里唯一"技术性"的一步。卡住了就把报错截图发给 Claude 网页版（[claude.ai](https://claude.ai)）问它怎么办——那个不用装，浏览器打开就能用。
>
> 那个页面上还会列出终端命令、VS Code 插件等其他安装方式，**你不用管，认准桌面版下载按钮就行**。

**换别的 AI 助手行不行？** 行，这个工具没绑定谁。功能强的（会开子任务、会弹选项让你点）体验最好；功能弱一点的会自动走简化流程——少开几路搜索、改成文字问答、简历先出网页版。改简历的规矩（只写真话）在哪个助手里都一样。

## 第 1 步：把工具下载到电脑上

1. 打开这个工具的 GitHub 页面。
2. 找到绿色的 **`< > Code`** 按钮，点它。
3. 在弹出的菜单里点 **Download ZIP**。
4. 下载完成后**双击那个 zip 文件解压**，你会得到一个叫 `autumn-recruitment-tracker` 的文件夹。
5. 把这个文件夹拖到你能找到的地方，比如桌面。

> 不会解压？把 zip 文件直接拖进 AI 的对话框，说"帮我解压这个文件"。

---

## 第 2 步：让 AI 装好它

回到 AI 助手的窗口，**把刚才那个文件夹直接拖进对话框**，然后打字：

> 这是一个自动监控校招岗位、还能帮我改简历的工具，帮我安装到我的技能目录里，装好之后告诉我。

拖不进去的话，就把文件夹路径复制给它：

- **Mac**：右键点文件夹 →（菜单出来后）**按住 Option 键**，"拷贝"会变成"**拷贝……为路径名称**"，点它，然后在对话框里粘贴。
- **Windows**：按住 **Shift** 右键点文件夹 → 选"**复制为路径**"，然后粘贴。

AI 会自己把文件放到该放的地方，装好会告诉你。**这一步你不需要理解它做了什么。**

## 第 3 步：发简历，看分析，确认方向

跟 AI 说：

> 用一下秋招求职助手。

它会先问你要简历。**这一步它只会要简历，不会同时问你别的**——因为后面那些问题的答案基本都能从简历里读出来，先问等于让你白想一遍。

**把简历文件拖进对话框就行。** PDF、Word、纯文本都可以，手机拍的照片也行（拍清楚点）。

它读完会先给你一份**简历分析**：

- **画像速览**：学历、专业、核心技能、你这份简历讲的是个什么故事
- **优势 3 条**：每条都指明是简历里哪句话支撑的
- **短板 2-3 条**：说清楚会在哪一步卡住你（比如"没有相关实习，简历筛这关就会减分"）
- **推荐 2-3 个岗位方向**：每个带契合度、推荐理由、这个方向常见的岗位叫法、想投的话得先补什么

> 这份分析只根据你简历里实际写着的内容。写不出来的它会直说"简历里没写，你补充一下"，不会替你猜、不会说好听话。

看完分析，它才带着答案来确认四件事——**你只需要确认或者纠正，不用从零想**：

1. 你是哪一届毕业（它从简历里读出来了）
2. 想投什么方向（选项就是刚才推荐的那几个）
3. 要不要顺便看实习（还是只看正式校招）
4. 现在是秋招还是春招

回答完，它会记下设置，还会按你的方向生成一份 **30-50 家公司的重点监控名单**（之后想加谁减谁随时说一句就行）。

设好之后就不用管了，每天到点它自己跑，跑完把清单给你。

## 之后每天怎么用

看到分数高的岗位，回一句就行：

> 帮我照着第 2 个岗位改简历。

它会走一遍改简历流程（下一节讲它怎么保证不瞎编），最后给你一份新简历，并问你"投了跟我说一声"。

投完了告诉它，它就开始帮你记进度；拿到面试了，还能让它陪你练：

> 我投了那个风控管培生。
> 字节让我去笔试了。
> 帮我准备某某公司的一面。
> 那家银行挂了。

## 改简历是怎么保证不瞎编的

这是这个工具最较真的地方。**简历上每一句话，你面试都答得上来**，这是硬要求。

- **先问清楚再动笔。** 你提到的每段新经历（尤其"我用 AI 做过 XX"这种），它会先问你：具体做了什么？你和工具各干了什么？做到什么程度了（只是自己跑通了，还是真有人在用）？问清楚才写。
- **STAR 写法。** 每条经历按"背景—任务—动作—结果"组织。结果只写真的——没有数字就写规模和状态（比如"个人使用，未对外发布"），**绝不编造指标**。
- **不硬凑。** 岗位要求里你没有的能力，宁可空着并告诉你"这块你缺，要不要补"，也不往简历里塞。
- **"这是短板"之前先挖一轮。** JD 要某项能力而你简历这块很薄，常见的原因不是你没做过，是没写出来。它会先问几个问题确认，挖完还是空才算短板。
- **保密。** 涉及前雇主、客户数据的经历只写方法不写细节。
- **改完给你交代。** 逐条告诉你改了什么、依据是哪句话、改前改后分数各是多少。
- **每一版都存档。** 哪家公司、什么岗位、什么时候改的，全记着。投得越多，它越懂你。

同样的规矩适用于深挖经历和面试排练：**数字记不清就标"约"或者干脆不记，绝不替你圆一个数**——编出来的数字面试被追问时会当场碎掉，那比没有数字糟糕得多。

## 帮你填网申：它碰什么，不碰什么

网申是校招里最耗人的一段——同样的信息在几十家公司的系统里重填几十遍。这个功能把它自动化，但**边界划得很死**。

**怎么用**：把网申链接发给它，说"帮我填这个网申"。你需要先在自己的 Chrome 里登录那个网站（登录这一步永远是你自己做）。

**它会做**：读表单结构 → 给你一张"哪个字段填什么"的对照表 → **你确认后**才开始填 → 每填一节读回来核对 → 填完停下让你检查。

**它绝对不碰**（写死在规则里，你让它碰也不行）：

- 身份证号、护照号、银行卡号、密码、验证码——**不代填，也不存进任何档案**
- 不替你注册账号，不替你过验证码/滑块/人机验证
- **不替你点提交。** 每一次点"提交"这类不可逆按钮前，都要重新问你一遍，不存在"这次会话已经授权过了"

表单里遇到红线字段，它会截图告诉你在哪一格，让你自己填。

**表单里已经有旧内容时**，它会给你一张"现值 → 改成什么 → 为什么"的对照表，让你看见自己将失去什么，而不是直接覆盖。

**前置条件**：需要浏览器自动化能力（Chrome 开一个调试开关，AI 会引导你）。装不上也不白费——它会退而给你一张"字段-答案清单"，你复制粘贴手填，个人信息档案照样攒着。

> **一句提醒**：部分招聘网站对浏览器自动化检测严格，理论上存在账号风险。这个功能内置了防护但无法完全避免，用之前心里有数。

## 投出去之后

它会帮你记完整的漏斗：**已投递 → 简历通过 → 笔试 → 一面 → 二面 → HR 面 → offer**（或者"挂了"、"放弃"）。

然后：

- 投出去**超过两周还停在"已投递"**的，日报里会提醒你催一下或者找内推问进度；超过一个月的直接说"疑似已挂，可以考虑放弃了"。
- 约好的笔试面试时间到了会提醒你。
- 已经投过的岗位不会再出现在截止预警里——投都投了，催也没用。
- 问它"哪一版简历过筛率高"，它会按版本算给你看。**但要注意样本量**：校招总共投几十份，版本之间差几个百分点没有任何意义，它自己也会提醒你这一点。这个数字能告诉你的是"这一版明显不行"（投了十几个一个没过），而不是"A 版比 B 版强 3%"。

## 拿到面试之后

三件事：

- **备题**——出行为题、动机题、专业题，外加两类最容易翻车的：**简历硬伤题**（空窗期、跨专业、实习短这些你自己心里有数的地方）和**反问环节**（"你有什么想问我的"）。它给题目和该用哪段经历来答，**不给你标准答案全文**——背稿面试官一眼看得出来。
- **模拟**——它演面试官，一次问一题。你答完它指出三件事：STAR 缺了哪块、有没有踩红旗话术（贬低前雇主、数字前后矛盾、背稿感）、同样的事实怎么说更好。可以让它开"追问加压"，对一件事连问三层为什么。
- **复盘**——面完把真题记下来。**真题比任何预测题都准**，同一家公司下次面试优先出这些。

**关键细节**：出题用的是**你投这家时用的那一版简历**，不是你最新那版——面试官手里拿的就是那份。这也是每次投递记一句"用的哪版简历"的价值所在。

## 你的数据安全吗

用得越深，它存的东西越多。老实告诉你都存了什么、存在哪：

| 存了什么 | 在哪 |
|---|---|
| 简历原件与各版本 | `resumes/` |
| **网申档案**（真实姓名、手机、邮箱、教育实习经历、开放题答案） | `resumes/webapply-profile.json` |
| **经历素材库**（你确认过的经历细节与故事） | `resumes/experience-bank.json` |
| 证件照 | `resumes/photos/` |
| 投递记录、面试题库 | `state/` |
| 你的设置 | `config.json` |

**这些全部只存在你自己的电脑上，不上传任何网站。** 并且：

- 工具自带保护设置：就算你把这个文件夹分享给别人、或者上传回 GitHub，**上面这些一个都不会被带出去**。
- **身份证号、银行卡号、密码从来不存**，任何文件里都没有——网申填表遇到这类字段是让你自己填的。
- AI 派出去搜岗位的那些子任务里，只带一段"画像摘要"（比如"2027 届会计硕士，会 Python/SQL"），**不含你的姓名、电话、邮箱、照片**。
- 网申填表时，你的真实信息只从本机浏览器写进表单，不经过第三方。

## 要花多少钱

诚实地说：取决于你用的 AI 助手怎么收费，这个工具管不了。它能管的是**尽量少用**，内置了这几道闸门：

- 平时**每天只跑两路公众号**，一周才全面扫一次所有平台。
- 出去找岗位的那些子任务用的是**便宜的小模型**（打分仍然由主模型亲自做，保证所有岗位一把尺子）。
- 每次最多深评 15 个新岗位，**同一个岗位永远只深评一次**，每次最多核实 5 家新公司。

改简历、填网申、深挖经历、面试排练这几个都是你开口才跑，不会自己烧钱。

想更省或更全，跟它说一声就能调。

## 出问题了怎么办

| 现象 | 怎么办 |
|---|---|
| 它没要简历，直接问我方向 | 说"**先看我的简历再问**"。正常一定是先要简历、给分析，再确认问题，顺序反了就打断它 |
| 简历它读不出来 | 把简历另存成 PDF 再发一次；手机拍的照片重拍清楚点 |
| 今天一个新岗位都没有 | **正常。** 清单最后一行会写"精简扫描 · 2 路"——平时扫描面本来就窄，不用重跑。周日的全面扫描会补上 |
| 找到的岗位方向不对 | 说"这些岗位方向不对，我要的是 XX 方向"，它会重新调关键词 |
| 匹配分看着不合理 | 说"XX 岗位的分数我觉得不对，重新评估一下" |
| 它说要改简历但没问我细节就写了 | 打断它，说"**你还没跟我核实经历细节**"。这是硬规矩，它不该跳 |
| 网申填表连不上浏览器 | 让它"检查一下浏览器自动化的依赖"，它会告诉你缺什么。实在不行让它给你字段清单手填 |
| 网申填错了/填漏了 | 它填完会停在提交前，**这时候就该逐条核对**。有问题直接说"第 X 项不对"，它改完重新给你看 |
| 面试排练出的题不对路 | 告诉它"这几道不像会问的"，或者直接给它你查到的面经 |
| 定时任务没跑 | 说"检查一下我的定时任务还在不在"，让它重新设一遍 |
| 完全不知道现在什么情况 | 说"**现在是什么状态？我设置了什么？监控了多少岗位？投了几个？**" |

## 常见问题

**我要自己写代码或者改配置文件吗？**
不需要，一次都不需要。所有调整——换方向、改届别、加减公司、改运行时间、改省钱程度——都直接用大白话跟 AI 说。

**这么省会不会漏掉岗位？**
它会记账：每条渠道跑了多少次、找到过多少新岗位、其中多少个高分。想看就问"各个来源的产出怎么样"。某条渠道连着好多次一无所获，平时就不跑它了（每周的全面扫描日照跑，不会永久失明），清单里会写明是哪条、怎么恢复。省成本这件事有据可查，不是拍脑袋。

**匹配分靠谱吗？**
它按固定量表打分（硬技能 35 分、经验相关 25 分、学历届别 15 分、证书语言 10 分、意向契合 15 分），**只认你简历里写了的和你亲口确认过的**，不会"猜你应该会"。当参考很好用，但重要岗位还是自己点开原链接确认一下。

**定时自动跑的时候，它会不会背着我干别的？**
不会。自动运行时它**只找岗位、只打分、只提醒**。改简历、填网申、深挖经历、面试排练、标记投递状态——这些全都必须你在场，一个都不会自动做。

**深挖经历要花多久？**
一次挖一段，五到八个问题，十分钟左右。挖到你开始答"记不清了"它就会停——那说明信息挖完了，再问只会逼你编。挖过的经历三个地方复用，不用重复挖。

**用了一段时间想换方向 / 换简历？**
换方向：说"帮我把监控方向改成 XX"。换简历：把新简历拖进去，说"用这份做我的主简历"，它会重新建档、重做一遍分析。

**这工具靠谱吗，会不会漏岗位或者搞错？**
会。它靠 AI 去各个网站找信息再判断，不是 100% 精确。**把它当成"帮你先筛一遍、把范围缩小"的助手**，重要岗位自己点链接确认。它省的是你每天翻十几个网站的时间，不是替你做决定。

**想直接出 PDF 简历？**
不装任何东西也能用——它会给你排版好的网页版简历（浏览器打开就能看、能打印成 PDF）。想一步到位直接出 PDF，说"帮我装上做 PDF 需要的工具"，它自己会装。装失败也不影响其他所有功能。

## 给愿意自己动手的人

技术细节看 `SKILL.md`（六条入口路由、运行步骤与降级策略）、`references/`（数据源轮转、评分量表、改简历流程、经历深挖、投递追踪、面试排练、网申填表规范与各网申系统的表单经验）、`config.example.json`（全部可调项）。首次运行后你的实际设置在 `config.json`（不入库）。内嵌的排版工具箱与改简历指引在 `vendor/`，说明见 `vendor/README.md`。

几个常用旋钮（都在 `config.json`，也都可以直接跟 AI 用大白话说）：

| 想干什么 | 改哪里 |
|---|---|
| 恢复成每天全面扫描 | `discovery.mode` 改成 `"full_daily"` |
| 换个日子做全面扫描 | `discovery.full_sweep_weekday`（0=周一，6=周日） |
| 彻底关掉某条渠道 | 把它的 lane id 写进 `discovery.disabled_lanes` |
| 调子任务用的模型 | `discovery.agent_model`、`resume.jd_fetch_agent_model` |
| 改截止预警提前几天 | `deadline.warn_days` |
| 改"投了多久算没动静" | `applications.followup_days` / `stale_days` |
| 改每次深评上限 | `resume.max_deep_evals_per_run` |

网申填表依赖 [web-access](https://github.com/eze-is/web-access) 提供的浏览器 CDP 能力（需单独安装），其余功能都不依赖它。各网申系统的表单经验记在 `references/webapply-patterns/`，**只记页面结构和选择器，不记任何个人数据**——欢迎补充你遇到的系统。
